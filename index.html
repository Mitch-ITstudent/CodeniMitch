Welcome to PC Parts Identification!

A computer is made up of different components that work together to perform various tasks. This website will help you identify the different parts of a computer and understand their functions.

15 Different Parts of a Computer

Explore the computer components below and learn what each part does.

1. CPU

Central Processing Unit

The CPU is the brain of the computer. It processes instructions and performs calculations.

2. Motherboard

The main circuit board that connects all computer components together.

3. RAM

Random Access Memory

RAM temporarily stores data that the computer is currently using.

4. GPU

Graphics Processing Unit

The GPU processes images, videos, and graphics displayed on the monitor.

5. HDD

Hard Disk Drive

A storage device used to save files, documents, pictures, and applications.

6. SSD

Solid State Drive

A fast storage device used to store computer data and applications.

7. PSU

Power Supply Unit

Provides electrical power to all the components inside the computer.

8. Computer Case

The enclosure that holds and protects the internal computer components.

9. CPU Cooler

Helps keep the processor cool and prevents it from overheating.

10. Case Fans

Move air inside the computer case to maintain proper airflow and cooling.

11. Monitor

An output device that displays images, videos, and information from the computer.

12. Keyboard

An input device used to type letters, numbers, and commands.

13. Mouse

An input device used to move the cursor, click, and select items on the screen.

14. Speakers

An output device that produces sound from the computer.

15. Network Card

Allows a computer to connect to a network through wired or wireless connections.

About This Website
